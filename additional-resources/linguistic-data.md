# {{ page.title }}

Transcriptions and linguistic data for the Tunica notebooks can be viewed online [here](/tunicalanguageresources/notebooks), or downloaded in a number of different formats.

This data was originally recorded in [Fieldworks Language Explorer (FLEx)](https://software.sil.org/fieldworks/). The full dataset can be downloaded by clicking the button below. To view this data on your computer, [download FLEx](https://software.sil.org/fieldworks/download/fw-91/fw-9125/) (ideally version 9.1). Double-clicking on the downloaded file should then bring up the option to open the file in FLEx.
